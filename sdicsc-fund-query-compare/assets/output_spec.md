# 输出规范

## 报告结构

智能体输出的Markdown报告应包含以下七个维度：

1. **基础信息** — 基金类型、规模、星级等基本资料
2. **业绩表现** — 各周期收益率与排名
3. **风险指标** — 回撤、波动率、风险调整收益
4. **持仓分析** — 资产配置、重仓股、行业分布
5. **基金经理** — 任职年限、管理规模、业绩表现
6. **费率与交易规则** — 管理费、申购赎回费、确认时间
7. **综合结论** — 差异雷达与场景匹配建议

每个维度包含：**数据表格** + **分析点评**（1-3句）

**序号规则**：
- 完整报告（7个维度）：使用序号标题，如"一、基础信息"、"二、业绩表现"等
- 部分维度输出：不使用序号，直接使用维度名称作为标题，如"基金经理对比分析"、"业绩表现对比"等
- 单维度输出：使用"XX对比分析"格式，如"基金经理对比分析"

## 输出要求与注意事项

- 使用Markdown表格格式展示数据
- **【重要】表格标题栏必须使用基金简称**（如"华夏成长混合"），不得使用基金代码（如"000001")
- 空值显示为"—"
- **【重要】无数据指标自动隐藏**：如果某个指标所有基金都无数据（均为"—"或空值），则该行不展示，避免冗余信息
- 引用基金时使用基金名称（如"华夏成长混合"）
- 数据时效性：报告中展示的数据均为基金净值日期的历史数据
- **【重要】末尾必须引用 `assets/disclaimer.md` 的免责声明**，完整展示免责声明内容
- 不得将异常数据当作正常结果展示
- 若基金代码由名称搜索得到，额外提示："该代码由名称搜索得到，可能存在偏差，请核实基金名称或直接提供准确的6位代码。"

**表格格式示例**：
```
| 指标 | 华夏成长混合 | 易方达蓝筹精选 | 南方优选成长 |
|------|-------------|---------------|-------------|
| 基金代码 | 000001 | 000002 | 000003 |
| 基金类型 | 混合型 | 混合型 | 混合型 |
| 风险等级 | 中高风险 | 中等风险 | 中低风险 |
```

**注**：详细的数据字段映射和分析要点见下文"各维度输出要点"。

## 各维度输出要点

### 一、基础信息

**数据字段**（从JSON `funds` 数组提取）：

**核心字段**（按逻辑顺序组织）：

**基金身份**：
- `code` — 基金代码
- `name` — 基金简称
- `type` — 基金类型
- `risk_level` — 风险等级
- `establish_date` — 成立日期

**净值表现**：
- `net_value` — 单位净值
- `net_date` — 净值日期
- `accumulated_net_value` — 累计净值
- `yield_day` — 日涨跌幅

**规模与管理**：
- `scale` — 基金规模
- `manager` — 基金管理人
- `custodian` — 基金托管人

**扩展信息**：
- `fund_star` — 基金星级
- `theme_labels` — 主题标签
- `min_buy` — 最低购买金额
- `fund_status` — 基金状态
- `is_auto_invest` — 是否支持定投

**分析要点**：同类/跨类判断、规模影响、星级参考、风险等级匹配、净值日期时效性。

### 二、业绩表现

**数据字段**（从JSON `funds[].performance` 提取）：
- `return_1m`、`return_3m`、`return_6m`、`return_1y`、`return_3y` — 各周期收益率
- `hs300_rate_1m`、`hs300_rate_3m` 等 — 沪深300同期收益率
- `rank_1m`、`rank_3m` 等 — 排名

**表格格式要求**：
- **时间维度为行**，每只基金一列，沪深300收益率单独一列
- **收益率和排名合并在一个格子**，格式为"收益率 (排名)"，便于基金数量较多时的紧凑展示
- **沪深300收益率单独一列**，与基金收益率并列展示

**推荐表格格式**：
```
| 时间维度 | 基金A | 基金B | 沪深300收益率 |
|----------|-------|-------|--------------|
| 近1月    | 9.92% (排名359/2316) | 18.92% (排名95/2316) | -2.08% |
| 近3月    | 83.14% (排名44/2314) | 98.09% (排名25/2314) | 7.44% |
```

**格式说明**：
- 每个基金列格式的：`收益率 (排名)`
- 排名格式：`排名/总数`，如 `359/2316` 表示在2316只同类基金中排名第359

**分析要点**：长短期业绩的稳定性和持续性，排名稳定性、超额收益变化、排名拐点。

### 三、风险指标

**风险字段**（从JSON `funds[].risk` 提取）：

**核心指标**（数值与排名合并在一个单元格展示）：
- `max_drawdown` + `max_drawdown_rank` — 近一年最大回撤（排名）
- `volatility` + `volatility_rank` — 波动率（排名）
- `information_ratio` + `information_ratio_rank` — 信息比率（排名）
- `sortino_ratio` — 索提诺比率
- `calmar_ratio` — 卡玛比率

**产品评级**（从 `prod_rating_detail` 提取）：
- `composite_rating` — 综合评级
- `anti_risk_capability` — 抗风险能力
- `profit_ability` — 盈利能力
- `stock_selection_ability` — 选股能力
- `performance_stability` — 业绩稳定性
- `reference_tracking_capability` — 基准跟踪能力
- `excess_earning_power` — 超额收益能力

**表格格式要求**：
- **数值和排名合并在一个格子**，格式为"数值 (排名排名/总数)"，便于紧凑展示
- **无排名的指标单独展示数值**
- **空值显示为"—"**，如果某个指标所有基金都无数据（均为"—"或空值），则该行不展示

**推荐表格格式**：
```
| 指标 | 基金A | 基金B |
|------|-------|-------|
| 近一年最大回撤 | 14.35% (排名1700/2749) | 16.25% (排名1202/2749) |
| 波动率 | 1.60% (排名2038/2749) | 1.41% (排名1488/2749) |
| 信息比率 | 3.26 (排名108/6176) | 3.81 (排名46/6176) |
| 综合评级 | 5星 | 5星 |
| 抗风险能力 | 4星 | 3星 |
```

**格式说明**：
- 有排名的指标：`数值 (排名排名/总数)`
- 无排名的指标：仅显示数值
- 空值统一显示为"—"

**分析要点**：风险调整后收益，回撤控制能力，回撤>30%高风险、信息比率>2强/<1弱、风险收益权衡、综合评级参考。

### 四、持仓分析

**持仓字段**（从JSON `funds[].holdings` 提取）：

**资产配置**（`asset_allocation`）：
- 各资产类型占比（股票、债券、货币资金等）
- 使用合并表格展示，便于对比

**股票持仓**（`stock_list` 数组）：
- `stk_code` — 股票代码
- `stk_name` — 股票名称
- `stk_price` — 股票最新价
- `stk_chg` — 股票最新涨跌幅
- `stk_ratio` — 股票占净值比例
- **展示格式**：每个基金单独展示，格式为"股票名称（占比）"，如"新易盛（7.97%）"

**债券持仓**（`bond_list` 数组）：
- `bond_code` — 债券代码
- `bond_name` — 债券名称
- `bond_ratio` — 债券占净值比例

**基金持仓**（`fund_list` 数组）：
- `fund_code` — 基金代码
- `fund_name` — 基金名称
- `fund_ratio` — 基金占净值比例

**行业配置**（`industry_allocation` 数组）：
- `industry_code` — 行业代码
- `industry_name` — 行业名称
- `industry_ratio` — 行业占净值比例
- **展示格式**：每个基金单独展示，格式为"行业名称（占比）"，如"制造业（82.44%）"

**分析要点**：风格暴露与持仓稳定性，股债比验证标签、集中度>60%高/<30%分散、重仓股重合度、行业配置差异体现分散价值。

### 五、基金经理

**经理字段**（从JSON `funds[].fund_managers[0]` 提取）：

**基本信息**：
- `name` 或 `manager_name` — 经理姓名
- `code` 或 `manager_code` — 经理代码
- `start_date` — 任职日期
- `end_date` — 离任日期
- `company` — 基金公司
- `manager_hold_days` — 任职天数

**业绩数据**：
- `annual_return` — 本基金任职期总回报
- `yield_hs300` — 同期沪深300收益率
- `annual_yield` — 从业以来年化回报
- `management_scale` — 管理规模（亿）

**扩展字段**：
- `manage_fund_list` — 管理基金列表（数组）
  - `mf_fund_name` — 在任基金名称
  - `mf_fund_code` — 在任基金代码
  - `mf_hold_start_date` — 在任基金管理开始时间
  - `mf_hold_end_date` — 在任管理结束时间
  - `mf_hold_days` — 在任基金管理天数
  - `mf_yield_since` — 在任基金任职收益
  - `mf_yield_hs300` — 在任基金同期沪深300
  - `mf_is_position` — 是否管理中
  - `mf_rank` — 在任基金排名

**代表基金**：任期收益最高的在任基金（`mf_is_position == "是"`）

**分析要点**：
- 经理稳定性：任职年限≥3年佳，频繁换经理=策略不连贯
- 管理规模：>200亿影响灵活性，<10亿规模过小
- 任职年化收益：与同期沪深300对比，超额收益能力
- 管理基金数：过多分散精力，建议<10只

### 六、费率与交易规则

**费率字段**（从JSON `funds[].fees` 提取）：
- `management` — 管理费率
- `custodian_fee` — 托管费率
- `sale_service_rate` — 销售服务费率
- `fee_type_name` — 收费方式（A类/C类等）
- `subscription` — 申购费率（多档位用分号分隔）
- `redemption` — 赎回费率（多档位用分号分隔）

**交易规则字段**（从JSON `funds[].trans_detail` 提取）：
- `buy_date` — 买入确认规则（包含确认日期和收益日期）
- `sell_date` — 卖出确认规则（包含确认日期和到账日期）

**分析要点**：长期持有的隐性成本、A类长期C类短期、QDII赎回T+5~7、费率档位影响。

### 七、综合结论

**必含内容**：
- **差异雷达**：收益能力、风险控制、业绩持续性、经理验证、持仓集中度、费率、流动性
- **场景匹配建议**：根据用户风险偏好和投资目标给出客观分析，不推荐

**基金引用格式**：
- **【重要】涉及基金代码时，必须同时展示基金名称**
- 正确格式：`华夏成长混合（000001）` 或 `华夏成长混合 (000001)`
- 错误格式：仅显示 `000001` 或仅显示基金代码
- 示例：在差异雷达或场景建议中，应写"华夏成长混合（000001）收益能力突出"，而非"000001收益能力突出"
