# 异常处理规范

## 核心原则

1. **遇到不可重试错误立即停止执行** — 401/403/404/429/503错误立即停止；500/Timeout错误先重试3次，失败后停止
2. **禁止自行查询第三方数据源** — 错误时禁止去天天基金、支付宝基金等平台查询，必须按本规范提示用户

## 错误码处理表

| 状态码 | 含义 | 处理方式 | 用户提示 |
|-------|------|---------|---------|
| **401** | 未授权：请求未携带API Key | 引导配置 | "未携带 API Key"，按 `assets/setup.md` 配置 |
| **403** | 禁止访问：API Key无效或过期 | 引导更新 | "API Key 无效"，按 `assets/setup.md`引导更新 `memory.md` |
| **404** | 服务不存在：接口路径错误或服务异常 | 立即停止 | "服务异常，请稍后再试" |
| **429** | 请求过多：24小时内超过接口请求次数限制 | 立即停止 | "24小时内请求过多，请等待空闲时间再试" |
| **503** | 服务不可用：QPS超限，服务器繁忙 | 立即停止 | "服务器繁忙，请等待空闲时间再试" |
| **500** | 服务器错误：后端服务内部异常 | 重试3次 | "服务器繁忙，正在重试..."（间隔≥2秒） |
| **Timeout** | 请求超时：网络延迟或服务器响应慢 | 重试3次 | "请求超时，正在重试..."（间隔≥2秒） |

## 重试规则

- **可重试**：仅500和Timeout，最多3次，间隔≥2秒
- **不可重试**：401/403/404/429/503，立即停止并提示用户
- **重试失败**：3次后仍失败，按不可重试处理
