# 基金查询与对比分析

## ⚠️ 核心注意事项（必读）

1. **禁止读取历史会话文件** — 只允许读取本次会话中脚本生成的JSON文件
2. **异常处理规范** — 脚本执行返回错误时，必须严格按照 `assets/error_handling.md` 处理
3. **禁止自行查询第三方数据** — 错误时禁止去天天基金、支付宝基金等平台查询，必须按错误处理规范提示用户
4. **风险提示必须完整** — 报告末尾必须完整展示 `assets/disclaimer.md` 的声明内容
5. **不暴露文件路径** — 输出中不提及JSON文件路径，直接输出Markdown文本报告

## 概述

提供**场外基金**多维度对比分析能力，支持从业绩、风险、持仓、基金经理等多个维度对比分析，帮助投资者快速甄别不同基金的优劣势，高效做出基金投资选择。 基金对比Skill由国投证券提供。

## 工作流程

```
用户请求 → 输入识别 → [名称→搜索映射代码] → 调用脚本取数（生成JSON） → 智能体读取JSON → 输出Markdown报告 → 结束
```

**执行步骤**：

0. **API Key 检查** — 读取 `assets/setup.md`，按其中说明确认已配置；未配置或后续返回异常码均按 setup.md 引导用户完成配置

1. **输入识别** — 纯数字=代码，含汉字/字母=名称，混合取数字。名称输入需读取 `assets/name_resolution.md` 执行映射

2. **数量检查** — 1只详情、2-5只对比；超过5只提示上限

3. **意图识别** — 根据用户请求关键词判断输出维度：
   - **业绩对比**：关键词含"业绩"、"收益"、"回报"、"表现" → 只输出"业绩表现"维度
   - **风险对比**：关键词含"风险"、"回撤"、"波动" → 只输出"风险指标"维度
   - **费率对比**：关键词含"费率"、"费用"、"成本"、"申购"、"赎回" → 只输出"费率与交易规则"维度
   - **经理对比**：关键词含"经理"、"基金经理"、"管理" → 只输出"基金经理"维度
   - **持仓对比**：关键词含"持仓"、"重仓"、"配置" → 只输出"持仓分析"维度
   - **基础对比**：关键词含"基础"、"基本信息"、"概况" → 只输出"基础信息"维度
   - **全面对比**：关键词含"全面"、"详细"、"完整" 或 无特定维度关键词 → 输出全部7个维度

4. **调用脚本取数** — 执行命令获取JSON数据：
   ```bash
   python3 scripts/get_fund_compare.py --funds "代码1,代码2"
   ```
   - 脚本自动完成：数据获取 → JSON文件生成（包含基金对比数据）
   - **stdout输出概要信息**（timestamp、summary、fund_count、fund_codes、output_files、meta），不输出详细funds数据，避免截断
   - **智能体必须从stdout输出的 `output_files.json` 字段值读取完整基金数据路径**，使用read_file工具读取该路径对应的JSON文件
   - ✓ 确认stdout包含 `output_files.json` 字段，从该字段值中获取完整基金数据的文件路径
  

5. **输出Markdown分析报告** — 根据步骤3识别的意图，读取 `assets/output_spec.md` 中对应维度的输出要点，结合脚本返回的基金数据输出报告：
   - **单维度输出**：只输出用户请求的维度，使用"XX对比分析"格式（如"业绩表现对比分析"）
   - **全维度输出**：输出全部7个维度，使用序号标题（如"一、基础信息"）
   - **末尾提示**：根据输出维度类型判断提示内容

## 输出规范

详见 `assets/output_spec.md`，包含报告结构、各维度分析要点、数据表格格式等完整说明
