# 基金对比

## Skill简介

提供场外基金多维度对比分析能力，支持从业绩、风险、持仓、基金经理等多个维度对比分析，帮助投资者快速甄别不同基金的优劣势，高效做出基金投资选择。

## 功能特性

**单只基金查询**：获取单只基金的详细信息
**多只基金对比**：支持2-5只基金的多维度对比分析

| 对比维度 | 核心指标 | 解读要点 |
|---------|---------|---------|
| 基础信息 | 基金类型、成立日期、基金公司、基金经理、规模 | 规模是否过大影响操作灵活度 |
| 业绩表现 | 近1月/3月/6月/1年/3年收益率、年化回报 | 长短期业绩的稳定性和持续性 |
| 风险指标 | 最大回撤、波动率、贝塔系数 | 风险调整后收益，回撤控制能力 |
| 持仓分析 | 前十大重仓股/行业分布 | 风格暴露与持仓稳定性 |
| 费用结构 | 管理费率、托管费率、申购/赎回费率 | 长期持有的隐性成本 |
| 基金经理 | 从业年限、任职回报、管理规模 | 经理稳定性与历史管理水平 |

## 使用示例

```
- 对比001480和720001这两只基金
- 介绍财通价值动量混合A这只基金
- 720001的业绩如何
```
