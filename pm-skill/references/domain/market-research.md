## 竞品分析

### 分析框架
| 维度 | 竞品 A | 竞品 B | 竞品 C | 我们的定位 |
|------|--------|--------|--------|------------|
| 目标用户 | | | | |
| 核心功能 | | | | |
| 定价模式 | | | | |
| GTM 渠道 | | | | |
| 优势 | | | | |
| 劣势 | | | | |
| 差异化机会 | | | | |

### 竞品类型
- **直接竞品**: 解决相同问题、面向相同用户
- **间接竞品**: 不同的解决方案但解决类似问题
- **替代竞品**: 用户目前的替代方案（包括手工/不做）

### 分析深度
- 快速：3-5 竞品，公开信息
- 标准：5 竞品，产品体验 + 公开信息 + 用户评价
- 深度：包含财务/团队/技术栈分析

## 用户画像

### 画像模板
| 维度 | 特征 |
|------|------|
| 人口统计 | 年龄、性别、地域、职业、收入 |
| 行为特征 | 使用习惯、购买行为、技术偏好 |
| JTBD | 功能性任务、情感性任务 |
| 痛点 | 当前方案的不满意之处 |
| 期望收益 | 理想状态 |
| 使用场景 | 何时、何地、与谁一起 |

### 画像原则
- 基于研究数据，不基于假设
- 3-5 个画像（太多则难以聚焦）
- 含反直觉洞察（不只是常识）

## 客户旅程地图

### 旅程阶段
```
认知 → 考虑 → 购买 → 使用 → 推荐
```

每个阶段分析：
- **触点**: 用户在哪里接触到产品？
- **行为**: 用户在这个阶段做什么？
- **情绪**: 用户的情绪曲线（高低点）
- **痛点**: 什么让用户沮丧或流失？
- **机会**: 我们能改善什么？

## 市场规模估算

### TAM / SAM / SOM
```
TAM（总可寻址市场）: 全球/全国范围的市场总规模
SAM（可服务市场）: 我们的产品/渠道可触及的市场
SOM（可获得市场）: 短期内实际可获得的市场份额
```

### 估算方法
- **自上而下**: 从行业报告宏观数据向下推导
- **自下而上**: 从客户数量 × 客单价向上计算
- **类比法**: 参考类似产品的市场表现

### 数据源
- 行业报告（Gartner, IDC, 艾瑞等）
- 上市公司财报
- 行业数据库（Crunchbase, IT 桔子等）
- 一手调研（问卷、访谈）

## 情感分析

### 数据来源
- 应用商店评论
- 社交媒体（微博、小红书、Twitter）
- 客服工单
- NPS 调查

### 分析维度
- **情感评分**: 正面/中性/负面比例
- **主题提取**: 用户最关心什么？
- **趋势变化**: 情感如何随时间变化？

---

## 更新指南

- 所有数据标注来源和时间
- 区分一手数据和二手数据
- 定期更新（市场数据每季度至少刷新一次）
- 中文输出
