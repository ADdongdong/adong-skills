> 综合自 pm-skills 的 pm-go-to-market 和 pm-marketing-growth 插件。
> 在发布阶段和 /pm-release 命令中使用。

## GTM 策略框架

### 核心要素
- 沙滩头细分 + ICP 定义
- 价值主张 + 消息设计
- 渠道选择 + 资源配置
- 发布节奏 + 成功指标

---

## 沙滩头细分

### 四大评估标准
| 标准 | 描述 | 评分 (1-5) |
|------|------|------------|
| 紧迫痛点 | 这个问题让他们多痛苦？ | |
| 付费意愿 | 他们愿意为解决这个问题付费吗？ | |
| 可赢取份额 | 我们能在这个细分市场取胜吗？ | |
| 推荐潜力 | 他们会向同类推荐吗？ | |

### 原则
- 一次聚焦一个细分市场
- 不同细分 → 不同价值主张
- Geoffrey Moore《跨越鸿沟》方法论

## ICP 定义

### 理想客户画像维度
- **企业（B2B）**: 行业、规模、收入、技术栈、决策流程
- **个人（B2C）**: 年龄、地域、收入、兴趣、技术使用习惯
- **JTBD**: 待完成的功能性 + 情感性任务
- **取消资格标准**: 谁不是目标（帮助团队说不）

## GTM 渠道

### 七大 GTM 动作

| 动作 | 描述 | 适用场景 | 典型工具/平台 |
|------|------|----------|--------------|
| 入站营销 | 内容/SEO/社交媒体 | B2B, PLG | 公众号、知乎、Medium |

| ABM | 目标客户营销 | B2B 大客户 | 定制化营销 |
| PLG | 产品驱动增长 | 自服务产品 | 免费试用 + 自助升级 |

## 增长飞轮

### 五种类型（Ognjen Boskovic）

| 类型 | 机制 | 示例 |
|------|------|------|
| 病毒式 | 用户邀请用户 | WhatsApp, Dropbox |
| 使用型 | 使用越多价值越大 | Google Docs, Notion |
| 协作型 | 团队内价值随人数增长 | Slack, Figma |
| UGC 型 | 用户产生内容吸引新用户 | YouTube, 知乎 |
| 推荐型 | 用户主动推荐 | 口碑传播, NPS 推荐 |

### 飞轮设计
```
{用户行为 A} → {产生结果 B} → {吸引新用户 C} → {更多行为 A}
```
正反馈循环：每一步驱动下一步。

## 消息 & 定位

### 价值主张陈述
```
对于 {target user}，
{product name} 是 {product category}，
它 {key benefit}。
不像 {competitor alternative}，
我们的产品 {unique differentiator}。
```

### 定位角度
- 品类创造者（定义新品类）
- 颠覆者（比现有方案好 10 倍）
- 利基精品（专注一个细分做到极致）
- 性价比冠军（同样的价值，更低的价格）

### 消息矩阵
| 受众 | 关注点 | 核心消息 |
|------|--------|----------|
| 用户 | 解决我的什么问题？ | {用户消息} |
| 决策者 | 值得投资吗？ | {价值消息} |
| 媒体 | 为什么有新闻价值？ | {故事消息} |

## 竞品作战手册

### 竞争定位
- 功能对比矩阵
- 我们的优势场景
- 竞品的优势场景

### 异议处理
- 竞品比我们便宜 → {应对}
- 竞品功能更多 → {应对}
- 竞品品牌更大 → {应对}

### 攻防策略
- 进攻：从哪里抢夺竞品用户？
- 防守：哪里布防防止用户流失？

## 北极星指标

### 商业游戏类型
| 类型 | 核心行为 | 北极星方向 | 示例 |
|------|----------|-----------|------|
| 注意力 | 内容消费 | 日活跃时长 | 抖音、YouTube |
| 交易 | 买卖行为 | 交易 GMV | 淘宝、美团 |
| 生产力 | 任务完成 | 活跃使用天数 | Notion、钉钉 |

### 7 条验证标准
1. 反映用户获得的核心价值
2. 可衡量长期业务成功
3. 对产品决策敏感
4. 团队可直接影响
5. 可测量且可追踪
6. 不为零和
7. 滞后指标（非虚荣指标）
