## 字段说明

### 必填（入库时必须确认）

| 字段 | 说明 | 示例 |
|------|------|------|
| id | 需求唯一标识 | REQ-012 |
| title | 一句话标题 | "支持微信 OAuth 登录" |
| description | 详细描述 | "用户可通过微信授权一键登录，无需手机号注册" |
| product | 所属产品 | "零感笔记" / "智能客服平台" |
| platform | 目标端 | iOS / Android / Web / 微信小程序 / 桌面端 / 服务端 / 全平台 |
| module | 功能模块 | "用户中心" / "笔记编辑" / "支付" / "消息通知" / "数据报表" |
| type | 需求类型 | 见下方需求类型枚举 |
| status | 当前状态 | pending / researching / planned / in-dev / done / on-hold / cancelled |
| priority | 优先级 | P0（必须）/ P1（需要）/ P2（可选） |
| source | 来源类型 | 见下方来源类型枚举 |
| source_detail | 来源详情 | "2026-06-05 产品评审会" / "竞品分析报告 §3.2" / "张三（用户反馈）" |
| created | 创建日期 | 2026-06-05 |
| updated | 最后更新 | 2026-06-05 |

### 需求类型枚举

| 类型 | 说明 | 示例 |
|------|------|------|
| `feature` | 新功能 | "支持语音转文字" |
| `optimization` | 功能优化 | "笔记列表加载速度优化" |
| `ux` | 体验改进 | "登录流程从 5 步缩减到 2 步" |
| `technical` | 技术需求 | "服务端接口重构" |
| `non-functional` | 非功能需求 | "页面响应时间 < 2 秒" |
| `data` | 数据相关 | "用户行为埋点" / "BI 报表" |
| `compliance` | 合规/安全 | "符合个人信息保护法" |
| `content` | 内容/文案 | "新手引导文案优化" |
