# 国投证券智能选股

提供各种基于自然语言选股的能力，例如根据财务指标、技术指标、市值等条件筛选符合条件的股票。

## 功能简介

支持通过中文自然语言描述各类选股条件，包括但不限于：

- **价格行情**：股价、涨跌幅、换手率、成交量、振幅等
- **市值指标**：总市值、流通市值等
- **财务指标**：市盈率(PE)、市净率(PB)、ROE、净利润增长、营收增长等
- **技术指标**：MACD、KDJ、RSI、均线等
- **资金指标**：主力资金净流入、北向资金增仓等
- **行业板块**：半导体、新能源等
- **组合条件**：多条件组合筛选
- **时间限定**：季度/月度/年度数据

## 快速开始

### 1. 配置 API Key

使用前需配置 API Key，获取地址：

```
https://www.sdicsc.com.cn/skills
```

### 2. 查询选股

配置完成后，直接使用自然语言描述选股条件即可：

```
市盈率低于20的半导体股票
股价大于100的股票
主力资金净流入的股票
最近一季度净利润增长超30%的股票
```

## 数据说明

数据仅供参考，不构成投资建议，结果默认不排序，可在条件中指定排序方式，支持连续追问与条件修正。
