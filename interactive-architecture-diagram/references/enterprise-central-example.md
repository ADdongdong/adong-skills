# 中车式采购协同：共享轨道建模示例

这个例子展示多种分区共用行边界的办法。它使用普通 `matrix/shared-tracks`、红金主题和显式 `style_role`；“中车式”仅描述本例的内容组织，不是模板或预设名称。

[可运行的 JSON](enterprise-central-example.json)包含七列、十条公共轨道。先将 JSON 复制到当前工作区，按原文修改内容，再通过 `--authoring_file` 提交。新建时可直接保留正文中的 `presentation_preset`，不用额外传配色；提交前检查后端矩阵主题能力。协议见[共享轨道矩阵](authoring-matrix.md)。

## 怎样拆分共享轨道

先列出各区域需要对齐的水平边界，取边界并集作为公共轨道。每列按自己的业务粒度覆盖这些轨道，不能各自计算独立行高。本例的覆盖如下，数字是跨度而非像素：

| 示例列 | 依次覆盖的轨道跨度 | 角色 |
| --- | --- | --- |
| 管理效益、管控分类 | 3 + 3 + 4 | frame |
| 支撑与业务核心 | 3 + 3 + 3 + 1 | 前两格 foundation、planning，后两格 business |
| 集采模式 | 1 + 7 + 2 | frame |
| 组织职责 | 1 + 1 + 2 + 1 + 2 + 1 + 2 | frame |
| 管理层级 | 1 + 4 + 5 | frame |
| 法人层级 | 5 + 5 | frame |

核心格内部再用 `items/columns` 表达 5 项或 7 项的横向分组。外围列设置 `style_role:frame`，核心列设置 `business`，基础和规划格显式覆盖；角色会向子项继承。颜色不根据 `core`、`foundation` 等业务 ID 推断。

## 怎样改成自己的图

- 增删、重排列，或改成三列、五列、九列；每列都完整覆盖公共轨道即可。
- 增删分区时重新取边界并集，并同步各列的 `start/span`；不保留没有意义的“十行”。
- 修改名称和业务 ID 不会触发布局或配色分支；已有图续改应保留稳定 ID，让角色继承对应到原节点。
- 底栏只表达真实的通栏事项，可删除；也可按内容新增普通业务列。
- 要蓝色主题，新建图时把 `presentation_preset` 改为 `blue-compact-v1`，结构和角色保持不变。

所有尺寸由同一通用编译器计算，本例不复刻旧模板中的固定列宽。当前模型支持列内跨行与格内嵌套，任意跨列合并仍不在协议范围内。
