# 【forp】银行流水核查

上传银行流水（支持多个 PDF），识别并整理后执行四步核查，生成多 sheet Excel。

## 我能帮你做什么

- **格式标准化**：日期统一、收支分列；金额无正负时按摘要推断（货款/回款→收入，材料款等→支出）；对手方名称清理，合并多银行流水
- **关联方打标**：匹配关联方清单，标注是否关联方与风险等级并高亮
- **异常筛查**：大额取现 / 高频往来 / 深夜交易 / 敏感摘要
- **资金闭环**：追踪大额支付去向，标记回流与体外循环线索

## 使用示例

- "帮我核查这几份银行流水"
- "按关联方清单筛查往来并导出 Excel"
- "对流水做异常交易与资金回流核查"

## 执行步骤

1. **脚本 file_to_json** — 识别 PDF 原始内容
2. **LLM 整理** — 映射为标准 9 列 JSON（含银行）
3. **脚本 json_to_excel** — 四步核查处理 → 多 sheet Excel 写盘 → 直接交给 LLM
4. **交付 Excel** — 最终回复包含核查摘要与 `file_path` 对应底稿

## 注意事项

- 流程不可跳步；`file_to_json` 返回后不算完成，必须继续调用 `json_to_excel`
- **中途禁止向用户输出任何文字，禁止 ReAct `action=finish`**；`tables_json` 只能放进命令入参
- 仅在 `json_to_excel` 返回后才允许 finish，并按 reference 交付 Excel（不上传、无 download_url）
- json_to_excel 内必须先核查再出表；可传入关联方清单与阈值配置
- AI 仅做「雷达」不做「判决书」，不做最终定性
