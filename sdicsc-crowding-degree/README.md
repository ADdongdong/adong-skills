# 国投证券行业拥挤度查询工具

依托成交额、总市值、换手率等指标，提供行业拥挤度数据查询服务。

## 功能简介

### 提供多维度行业拥挤度指标查询：

- **资金占比**：行业成交额占全市场比例
- **总市值占比**：行业总市值占全市场比例
- **换手率**：行业换手率水平
- **分位数**：当前指标在历史区间中的分位数位置
- **趋势分析**：本周、上周、上上周环比变化

### 支持查询全市场各行业指数的拥挤度数据，包括：

- 半导体、互联网、医药、新能源等热门行业
- 5日维度和20日维度分析

## 快速开始

### 1. 配置 API Key

使用前需配置 API Key，获取地址：

```
https://www.sdicsc.com.cn/skills
```

### 2. 查询行业拥挤度

配置完成后，直接询问即可：

```
半导体行业拥挤度
互联网还能入场吗
新能源市场情况
医药行业是否过热
```
