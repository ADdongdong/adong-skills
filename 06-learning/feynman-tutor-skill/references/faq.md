# 常见问题（FAQ）

## Q1：学完一个模块想跳过下一个行不行？

不行。模块之间有依赖关系，跳过会导致后面的概念听不懂。但你可以选「我学过，跳过」——系统会出一道验证题，答对就跳过，答错就老老实实学。

## Q2：中途想换目标等级（从高一级降到低一级）怎么操作？

直接告诉教练"我想把目标降一级"就行。教练会确认你的选择，然后按本学科阶梯上的新目标调整教学深度。注意：只能降不能升——升级需要重新评估你已学概念是否达到更高标准。

## Q3：能不能用这个 skill 复习之前学过的？

可以。说"复习"或"我想复习上次学的"，教练会从你的掌握度记录里拉出复习队列，用输出型验证（让你重新讲一遍）检测你是否还记得。答对维持掌握度，答错下调一级并重新入队列。

## Q4：学到一半退出，下次怎么继续？

直接说"继续学习"。教练会从上次断点处恢复——告诉你"你上次学到了【概念名】的【哪个步骤】"，然后从那里接着讲。不需要重头开始。

## Q5：这个 skill 支持哪些输入方式？

三种：① 直接说概念名（"教我梯度下降"）；② 给 GitHub 仓库链接；③ 上传文件（PDF/文档）。如果文件解析失败，会自动降级为让你口述概念名。

## Q6：答错了会不会被"惩罚"？

不会。答错是正常学习过程，教练不会批评你。答错后会诊断你为什么答错（概念混淆？缺前置知识？表达问题？），然后对症补强。唯一的"后果"是概念掌握度标记为 weak 或 ok，但这只影响复习频率，不影响任何评分。

## Q7：学完一个概念需要多长时间？

因人而异，教练不预估时长。简单概念可能 5 分钟过，复杂概念可能需要多轮补强。原则是"懂了才算完"，不赶进度。累了随时可以说"休息"，下次继续。

## Q8：觉得类比不合适怎么办？

直接说"这个比方我没感觉"或"换个例子"。教练会换一个完全不同领域的类比重讲，不会复读原来的。你也可以自己举一个你觉得贴切的类比，教练会基于你的类比帮你修正理解。
