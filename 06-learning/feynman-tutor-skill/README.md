# 费曼学习法 · 真懂教练

> 确保你真正学懂一个概念，而不是假装学懂。

（本说明随 skill 一同发布；完整文档与更新见 [GitHub 仓库](https://github.com/ADdongdong/feynman-tutor-skill)。）

## 这个 skill 做什么

用费曼学习法当你的自学教练：用生活化类比开场让你秒懂原理 → 追问让你用自己的话复述 → 诊断你卡在哪 → 对症补强 → 直到你能把它讲给别人听。不靠「我懂了」这种自我欺骗式确认，所有掌握都用你的主动输出（说/写/画）来验证。

**怎么开始**：直接说「教我 XX」「我想学 XX」「帮我理解 XX」；或把工作里撞到的不懂术语贴出来，进入上下文模式。

## 工作流程（节点 1 → 8）

```
节点1 学科选择 → 节点1.5 上下文模式(可选) → 节点2 目标分级
   → 节点3 模块计划 → 节点4 LECTURE(类比+配图) → 节点5 HOMEWORK(出题)
   → 节点6 ASSESS(评估) → 节点7 PRACTICE(做中学) → 节点8 MODULE_DONE(归档)
                              │
                       评估不通过
                              ↓
                  DIAGNOSE → REMEDIATE → 回到 HOMEWORK/LECTURE
```

- **节点 4-6** 是「讲 → 你复述 → 我考你懂没懂」
- **节点 7 PRACTICE** 是考过后「真刀真枪用一下」，按目标深度触发（见下）
- **节点 8** 标记掌握并归档到 Obsidian

## 核心教学原则

| # | 原则 | 行为体现 |
|---|---|---|
| P1 | 不通过不放行 | 评估不通过 → 诊断补强，绝不直接放行到下一概念 |
| P2 | 输出型学习 | 验证要求你主动输出（说/写/画），不靠点「我懂了」 |
| P3 | 前置检测 | 进新概念前检测前置知识，缺则插微课 |
| P4 | 不讨好 | 难≠降级，先诊断根因（概念混淆/缺前置/表达问题）再行动 |
| P5 | 复习优先 | 先完成当日复习队列再学新的（上下文模式除外） |
| P6 | 去伪精确 | 不输出进度% / 预估时长 / 段位 |
| P7 | 即时反馈优先 | 你回答后第一条必须是反馈（✅ 对在哪 / ⚠️ 差在哪），再讲解 |
| P8 | 主动配图 | 流程/结构/对比/几何/状态/算法/公式类概念，讲解时主动配图（默认 Mermaid，表达不了用 SVG） |

## 掌握深度按学科本族化（v1.1.6）

目标分级**不再写死**「能看懂 / 能用上 / 能设计」，而是按**学科**显示本族化的掌握阶梯。每个学科 3~5 级、逐级加深；底层「通用深度引擎」只认整数深度与相对位置，本族词只决定这串数字「对外叫什么」。

**相对位置规则（PRACTICE 触发依据，所有学科通用）：**
- 最浅级（L1）→ 跳过练习
- 中间级（L2 … L(n-1)）→ 轻量版：情境判断题
- 最高级（Ln）→ 重量版：设计/推导任务

## 上下文模式（节点 1.5，即时学习入口）

工作中撞到不懂的概念（一行报错、一段注释、一个文档术语），不想正经开课、只想顺手学到够用——把上下文贴出来并说「这个我不懂」，即可进入：

- agent 读上下文、**推断你只需达到本学科的哪一级**（相对位置），并给出理由
- 以本族词预选该等级（如历史显示「迁移类比」、数学显示「证明推导」），**等你确认/改选后才开讲**——推断只是默认值，可一票否决
- 走 fast-path：跳过复习队列，先解决眼前这个点；学完正常归档

## 主动配图（P8）

概念属流程/步骤、结构组成、易混对比、空间几何、状态变化、算法步骤、公式关系，且纯语言难以描述时，讲解时**主动配图**，不等你卡住再补：

- 默认 **Mermaid**（聊天面板直接渲染、Obsidian 原生支持）
- **SVG** 当 Mermaid 表达不了（精确几何、量化柱图、算法分步状态快照、拟物图）
- 所有图的源码在节点 8 归档时一并写入 Obsidian 笔记的代码块

## 代码/源码学习闭环（v1.1.7）

学习目标是 **GitHub 仓库 / 本地代码仓库** 时，从"学概念"升级为"学项目"：

- **读源码定向**：架构图/README → 入口文件 → 模块划分 → 调用链/依赖图，先看清项目全貌再逐模块学
- **模块级大作业**：每个模块标注是否配大作业（不要求每个知识点都有）；在 `feynman/lab-<模块>` 分支上做**动手实验**（预测 → 改动 → 验证 → 结论），改代码看效果，比打断点更有趣、记得更牢
- **按模块自动建/切分支**：一个模块 = 一个 `feynman/lab-<模块>` 分支，每次实验一次 commit，作业留痕可回看；切换前自动检查工作树，绝不带脏状态切
- **四态判定**：学习副本 / 自建学习 repo / 工作区项目 / 临时片段，先确认"改动影响谁"再决定实验自由度——只影响自己随便玩，会影响团队则轻量干预 + 强制分支
- **双轨归档**：分支 NOTES.md（项目上下文内的实验细节）+ Obsidian（概念总结 + 作业记录子块）

完整规则见 skill 内 `references/code_learning_loop.md`。

## 学习总结归档到 Obsidian（前置依赖）

节点 8 会把每次学习总结成一个 Markdown 文档，同步到本机 Obsidian vault：`费曼学习/{学科}/{概念}.md`。

**前置依赖**：需本机已安装 [Obsidian](https://obsidian.md) 并配置默认 vault，且可通过 `obsidian-cli` 调用（`obsidian-cli print-default --path-only` 返回 vault 路径）。

**未满足时**：节点 8 先检测，**检测不到 Obsidian 则不进入归档逻辑**，仅对话输出学习总结，不影响主流程。该功能仅面向 Obsidian 用户；不使用 Obsidian 的用户无需任何配置，学习体验一致。

**目录策略**：根目录固定 `费曼学习/`；一级目录 = 节点 1 所选学科名（不浮动，保证同概念稳定定位同一文件）；同概念再次学习 → 追加到同一文档，不覆盖历史。
