# Learning Review System

## Overview

一套从"发现问题"到"补足漏洞"到"内化认知"的完整学习闭环系统。核心逻辑：你的提问暴露思维模式 → 分析漏洞找到知识缺口 → 选主题系统性学习 → 每周用苏格拉底式提问帮你把读过的东西真正变成自己的认知。

## Core Capabilities

### 1. 每日提问复盘

**触发场景**：每天固定时间（建议 9:00 AM）自动运行，或用户手动要求回顾前一天提问。

**执行流程**：

1. 检索前一天对话（使用 conversation_search，查询用户提问、困惑、概念理解）
2. 总结提问内容——按主题分类列出
3. 分析思维与知识漏洞（四个维度）：
   - 知识盲区：哪些概念理解有偏差或不完整？
   - 思维模式：提问方式反映什么思维习惯？（偏直觉/偏经验/偏类比/偏逻辑？）
   - 认知偏差：是否存在幸存者偏差、确认偏误、锚定效应等？
   - 知识体系缺口：在哪个领域缺乏系统性认知？
4. 推荐一本书的具体章节——书名+章节名+概要+为什么能补漏洞+阅读建议

**关键规则**：
- 分析必须有依据，引用用户实际说过的话，不泛泛而谈
- 如果前一天无对话，推荐一章日常学习内容
- 书籍范围：认知科学、思维方法论、金融投资、经济学、心理学、系统思维、决策科学

**输出格式参考**：详见 `references/daily_review_template.md`

### 2. 每月主题学习推荐

**触发场景**：每月1号固定时间（建议 9:00 AM）自动运行，或用户手动要求推荐学习主题。

**执行流程**：

#### Phase 1：推荐4个主题

1. 检索近期对话，了解当前关注点和上月是否已选主题
2. 选择4个主题，覆盖4个维度：

| 维度 | 标记 | 选择逻辑 |
|------|------|----------|
| 认知维度 | 🧠 A | 补用户的思维漏洞（如系统动力学、认知偏差） |
| 专业维度 | 💼 B | 补业务/专业深度（如ABS法律结构、金融工程） |
| 跨界维度 | 🌍 C | 拓展视野（如行为经济学、制度设计） |
| 新世界维度 | 🔭 D | **与过往对话完全无关**（如进化论、宇宙学、人类学） |

3. 每个主题推荐2-3本书（🟢浅入门 → 🟡中进阶 → 🔴深专业）

**主题D的硬性要求**：
- 在用户过往对话中从未出现
- 和用户职业、日常关注点无直接关联
- 能让用户产生"原来还有这样一种看待世界的方式"的感觉
- 有足够深度，不是猎奇式浅尝辄止

**主题池参考**：详见 `references/theme_pool.md`

#### Phase 2：选定后生成月度学习计划

用户选定主题后，立即生成详细学习计划：

1. **本月学习目标**（2-3句话）
2. **每周阅读清单**（4周，具体到哪本书哪几章）

| 周次 | 阅读任务 | 核心概念 | 预计用时 | 阅读方式建议 |
|------|----------|----------|----------|-------------|
| 第1周 | 🟢浅入门书：具体章节 | ... | ... | ... |
| 第2周 | 🟢浅入门书：后半部分 | ... | ... | ... |
| 第3周 | 🟡中进阶书：核心章节 | ... | ... | ... |
| 第4周 | 🔴深专业书：选读章节(可选) | ... | ... | ... |

3. **每周思考题**（每周3个，层次递进）：
   - 问题1：概念理解型（"XX是什么？"）
   - 问题2：联系应用型（"这和你日常工作/生活中的XX有什么相似之处？"）
   - 问题3：批判反思型（"如果XX的前提不成立，会发生什么？"）

4. **月末总结框架**：
   - 学到的3个核心概念
   - 改变认知的1个观点
   - 可应用到日常工作的1个洞察

**输出格式参考**：详见 `references/monthly_plan_template.md`

### 3. 每周苏格拉底提问回顾

**触发场景**：每周一固定时间（建议 9:00 AM）自动运行，或用户手动要求回顾本周学习。

**执行流程**：

1. 检索本月1号左右对话，确定用户选择了哪个主题
2. 计算当前周次（1-7号→第1周，8-14→第2周，15-21→第3周，22-月末→第4周）
3. 检索最近7天对话，了解实际阅读进度（可能超前或滞后）
4. 生成5个苏格拉底式提问

**五问结构**：

| # | 问题类型 | 核心逻辑 | 示例 |
|---|----------|----------|------|
| 1 | 概念重构 | 用自己的话说 | "用自己的话，[核心概念]是什么？" |
| 2 | 类比迁移 | 和已知事物联系 | "把[概念]类比到你熟悉的[场景]，最像什么？" |
| 3 | 边界追问 | 什么时候不成立 | "[概念]在什么条件下失效或反转？" |
| 4 | 冲突检验 | 和已有认知碰撞 | "这个概念和你之前理解的[认知]有什么矛盾？" |
| 5 | 行动锚定 | 能用到哪里 | "下周可以做的一个小改变是什么？" |

**特殊处理**：
- **第1周**：问题偏轻松，建立入门信心；问题2优先类比日常生活
- **第3周**：问题偏深，刻意挑战二元分类倾向和工程师谬误
- **第4周**：附加月末总结三问（3个核心概念 + 1个改变认知的观点 + 1个可应用洞察）
- **进度滞后**：按实际阅读进度调整提问难度，不按原计划周次硬推

**提问原则**：
- 不问"你读了吗"——这是检查作业，不是引导思考
- 问的是"你怎么理解"——让用户用自己话重构概念
- 追问"如果…会怎样"——突破二元思维
- 联系日常——把抽象概念锚定到用户熟悉场景
- 承认不确定——回答有道理但不标准时，追问"什么情况下成立？什么情况下不成立？"

**输出格式参考**：详见 `references/weekly_review_template.md`

## Automation Deployment Guide

将三个模块部署为定时任务时，使用 automation_update 工具：

| 任务 | 推荐频率 | RRULE |
|------|----------|-------|
| 每日提问复盘 | 每天 9:00 | `FREQ=DAILY;BYHOUR=9;BYMINUTE=0;BYSECOND=0` |
| 每月主题学习 | 每月1号 9:00 | `FREQ=MONTHLY;BYMONTHDAY=1;BYHOUR=9;BYMINUTE=0;BYSECOND=0` |
| 每周提问回顾 | 每周一 9:00 | `FREQ=WEEKLY;BYDAY=MO;BYHOUR=9;BYMINUTE=0;BYSECOND=0` |

部署时将各模块的 prompt 内容（含详细步骤和输出格式）写入 automation 的 prompt 字段。

## Customization Notes

此 skill 的设计基于以下用户画像，部署到其他用户时需调整：

- **思维特征**：约束驱动的工程师思维，善于二元分类和锁叠加，有工程师谬误倾向
- **知识缺口**：系统动力学（反馈回路、涌现效应、紧耦合系统行为）
- **职业背景**：投行系统产品设计者
- **专业领域**：债券立项、批文额度、ABS储架发行、函证业务

调整要点：
1. 更新主题池中的专业维度（B维度）为新用户所在行业
2. 更新类比迁移问题中的锚定场景（从投行/产品改为新用户熟悉的领域）
3. 更新冲突检验问题中的"已知认知"引用
4. 新世界维度（D维度）无需调整——它本身就是与用户无关的

## Tone & Style

- 简洁直接，像朋友聊天，不说教
- 分析有理有据，引用用户原话，不泛泛而谈
- 推荐书籍必须真实存在，不编造
- 允许用户回答不完美，追问而非纠正
- 每周提问"不用全部回答，挑有感觉的聊聊就行"
