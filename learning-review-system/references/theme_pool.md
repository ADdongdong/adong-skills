# 主题池参考

## A. 思维/认知维度

补用户的思维漏洞和认知偏差。

| 主题 | 核心概念 | 适配场景 |
|------|----------|----------|
| 系统动力学与反馈回路 | 增强回路、调节回路、延迟、系统陷阱 | 已知知识缺口，优先级高 |
| 认知偏差与决策科学 | 确认偏误、锚定效应、可得性偏差 | 做决策时容易被直觉误导 |
| 复杂系统与涌现行为 | 涌现、非线性、紧耦合、脆性 | 约束叠加≠安全叠加的认知缺口 |
| 博弈论与策略思维 | 纳什均衡、囚徒困境、信号博弈 | 多方利益博弈场景 |
| 不确定性下的决策 | 概率思维、贝叶斯推理、预期值 | 习惯二元判断，缺乏概率视角 |

## B. 业务/专业维度

补用户的业务深度和专业认知。

| 主题 | 核心概念 | 适配场景 |
|------|----------|----------|
| 投行监管政策演进 | 注册制vs审核制、信息披露、市场化定价 | 需理解政策变迁背后的逻辑 |
| 资产证券化(ABS)法律结构 | 真实出售、风险隔离、SPV、基础资产 | ABS业务需要深入法律结构 |
| 金融工程基础 | 衍生品、风险度量、VaR、对冲策略 | 需理解量化金融底层逻辑 |
| 审计逻辑与内控体系 | 审计证据、内控五要素、函证逻辑 | 函证业务需理解审计底层逻辑 |
| 投行数字化转型路径 | 金融科技、智能审核、数字化流程 | 产品设计需要理解行业趋势 |

**适配其他用户时**：将此维度替换为新用户所在行业的专业主题。

## C. 跨界/视野维度

拓展视野，用其他领域的思维框架启发当前工作。

| 主题 | 核心概念 | 跨界价值 |
|------|----------|----------|
| 产品思维与系统设计 | 用户心智模型、渐进式披露、反馈循环 | 设计更好产品交互 |
| 信息架构与复杂表单设计 | 信息层次、分组逻辑、减少认知负荷 | 设计更清晰的复杂表单 |
| 制度设计与组织行为 | 制度激励、博弈均衡、组织文化 | 理解制度如何塑造行为 |
| 行为经济学与激励机制 | 损失厌恶、心理账户、助推 | 设计更有效的激励和引导 |
| 技术史与产业演进逻辑 | 技术S曲线、范式转移、网络效应 | 理解行业变迁的底层规律 |

## D. 推开新世界的窗户

**核心要求**：与用户过往对话、职业、日常关注点完全无关。

| 主题 | 核心概念 | 推开什么窗户 |
|------|----------|-------------|
| 进化论与自然选择 | 适应性、变异、累积选择、分支进化 | 从生物学理解"无需智能设计也能产生复杂秩序" |
| 宇宙学与大尺度物理 | 尺度、时间、熵、暗物质 | 从星辰理解"人类尺度在宇宙中微不足道" |
| 人类学与文明起源 | 文化、意义、亲属制度、仪式 | 从田野理解"你以为理所当然的其实是文化建构" |
| 音乐理论与声学 | 结构、和谐、节奏、共振 | 从声音理解"秩序可以在时间中涌现" |
| 建筑学与空间哲学 | 空间秩序、体验、庇护、边界 | 从空间理解"物理结构塑造心理体验" |
| 植物学与生态网络 | 共生、竞争、根系网络、菌根 | 从根系理解"看不见的连接比看得见的更重要" |
| 古典哲学与存在主义 | 自由、责任、荒谬、选择 | 从追问理解"意义不是被发现的，是被创造的" |
| 语言学与符号学 | 编码、解码、符号、意义滑动 | 从语义理解"你以为在传递信息，其实在传递符号" |
| 地质学与深层时间 | 变迁、沉积、侵蚀、时间尺度 | 从地层理解"人类时间尺度在地质尺度上微不足道" |
| 艺术史与视觉认知 | 感知、表达、凝视、再现 | 从图像理解"你看到的不是世界，是文化的滤镜" |
