# 国投证券行情查询

通过自然语言描述，实时获取股票、指数、ETF板块的行情数据，包括分时、K线、涨跌幅排名等信息。

## 功能

- 实时行情查询，支持单个股票、指数、ETF、板块
- 批量行情查询
- 分时数据
- 日/周/月/年K线及分钟K线
- 股票、板块、ETF涨幅排名
- 支持沪深京A股、港股股票

## 快速开始

1. 获取 API Key：访问 https://www.sdicsc.com.cn/skills
2. 配置 API Key 后即可查询

## 示例

```
查询国投资本今天的行情
今天涨幅排名靠前的板块
今天涨幅前30的个股
对比国投资本与中信证券的走势
```

## 股票代码格式

- 上海股票: `sh600000` 或 `600000`
- 深圳股票: `sz000001` 或 `000001`
- 北京股票: `bj920000` 或 `920000`
- 香港股票: `h00700` 或 `hk00700`
