# 图表成文测试文档

## 流程图示例

这是一个简单的流程图，正文包含 **加粗文字**、`行内代码` 和 [链接](https://example.com)。

```mermaid
graph LR
    A[开始] --> B{条件判断}
    B -->|是| C[处理]
    B -->|否| D[跳过]
    C --> E[结束]
    D --> E
```
