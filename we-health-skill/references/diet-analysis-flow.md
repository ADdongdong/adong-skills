# 饮食分析完整流程

> 本文件由 SKILL.md 主流程按需引用，不可独立执行。
>
---

## 核心规则

| 规则 | 说明 |
|------|------|
| AI 本地识别饮食 | 禁止 `file_list` 传图、禁止凭本地知识分析（结论必须调 API 获取） |
| 餐别与健康信息分两轮 | 第 1 轮处理餐别（用户文本已提及则直接采用并跳过确认，否则按上传时间推断并确认；禁静默采用推断值、禁同轮追问健康信息）；餐别确定后第 2 轮收集健康信息（上下文齐全时免询问） |
| 信息充分性判断 | 上下文已有信息直接复用，缺失才问；首次询问后仍有缺失最多再追问 1 轮；身高体重由 AI 换算为 cm/kg |
| BMI 计算 | 体重(kg) / (身高(m))²，四舍五入取整（如 20.76 → 21）；BMI 由 AI 根据身高体重计算，禁止向用户索要 |

---

## 流程

### 1. 饮食识别 + 餐别确认（第 1 轮，仅确认餐别，禁止追问健康信息）

识别图片中所有饮食，顿号连接（如「红烧肉、清炒菠菜、米饭」或「拿铁咖啡」），无法识别的标注「未知食物」；非饮食图片不触发本意图（由图片前置分流拦截）。

**餐别来源优先级：用户文本明确提及 > 按上传时间推断。** 若用户在上下文中已明确提及餐别（如「帮我分析一下今天的晚餐」「看看我午饭吃得怎么样」），直接提取该餐别，**跳过餐别确认步骤**，第 1 轮仅输出饮食识别结果后即进入第 2 轮。

按上传时间推断餐别（含头不含尾，如 10:00 属午餐）：

| 上传时间 | 推断餐别 |
|---------|---------|
| 05:00-10:00 | 早餐 |
| 10:00-14:00 | 午餐 |
| 14:00-17:00 | 加餐 |
| 17:00-22:00 | 晚餐 |
| 22:00-05:00 | 加餐（夜宵） |

**本轮只输出饮食识别结果 + 餐别确认（或直接采用用户提及的餐别），严禁同时询问健康信息。** 即使上下文缺失健康信息，也不得在本轮追加。健康信息留到第 2 轮处理。

**情况 A — 用户已提及餐别**（跳过确认，直接采用）：

> 我识别到这餐的饮食有：红烧肉、清炒菠菜、米饭。您提到这是**晚餐**，我直接按晚餐为您分析。

**情况 B — 用户未提及餐别**（按上传时间推断，需确认）：

> 我识别到这餐的饮食有：红烧肉、清炒菠菜、米饭。根据您上传的时间，这应该是**晚餐**，对吗？如果不是，请告诉我当前的餐别（早餐/午餐/晚餐/加餐）。

用户确认或修正后采用对应餐别；用户表示不确定时采用推断餐别（降级）。餐别确定后才进入第 2 轮。

### 2. 健康信息收集（第 2 轮，餐别确认后才执行）

所需信息：年龄、性别、身高（cm）、体重（kg）、疾病史、过敏史（无则填「无」）。

- **上下文已含全部信息** → 跳过询问，直接进入步骤 3（此情况下第 2 轮无声输出，不向用户提问）
- **有缺失** → 一次性询问所有缺失项；仍有缺失最多再追问 1 轮，之后无论是否补齐均进入步骤 3（未提供的填「未知」）

询问话术示例（假设全部缺失）：

> 为了给您更精准的饮食分析，请提供以下信息：
> 1. 年龄  2. 性别  3. 身高（cm）  4. 体重（kg）
> 5. 疾病史（无则回复「无」）  6. 过敏史（无则回复「无」）

### 3. 组装 query 并调用 API

**query = 意图前缀 + 餐别与饮食 + 健康信息**，三段拼接：

| 段 | 规则 |
|---|------|
| 意图前缀 | 用户有主动提问 → 沿用原话（去寒暄留核心）；仅上传图片无文字 → `帮我分析饮食` |
| 餐别与饮食 | `{餐别}：{饮食}` |
| 健康信息 | `，用户健康信息：年龄={年龄}，性别={性别}，身高={身高}cm，体重={体重}kg，BMI={BMI}，疾病史={疾病史}，过敏史={过敏史}` |

示例（用户主动提问）：

```
这顿饭热量高吗，晚餐：红烧肉、清炒菠菜、米饭，用户健康信息：年龄=30，性别=男，身高=170cm，体重=60kg，BMI=21，疾病史=高血压+糖尿病，过敏史=海鲜、花生
```

query 含特殊字符，统一用 `--stdin` 调用：

```bash
python3 scripts/query.py --stdin << 'EOF'
{
  "query": "这顿饭热量高吗，晚餐：红烧肉、清炒菠菜、米饭，用户健康信息：年龄=30，性别=男，身高=170cm，体重=60kg，BMI=21，疾病史=高血压+糖尿病，过敏史=海鲜、花生"
}
EOF
```

### 4. 展示结果

完整展示 `markdown_content`（不得删减截断），末尾附加免责声明：

> ⚠️ 以上健康信息仅供参考，具体诊疗请遵医嘱。如有紧急情况请立即就医或拨打 120。
