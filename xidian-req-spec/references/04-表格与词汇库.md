# 04 表格与词汇库

> 全部取自 v4.0.5 实测统计，写需求时**优先从中选词**，保证术语一致。

## 一、明细表（最高频，112 张表 / 281 个"按钮"条目）

### 1.1 操作说明表 —— `名称 | 类型 | 规则/说明`
用于页面按钮、图标、列表操作、二级页面元素。

|---|---|---|

> 表单控件类（单行文本 / 下拉选择 / 日期 / 开关 / 附件）如出现，沿用同类写法。
> 遇到词表里没有的类型：**优先复用已有词**，确需新增时全文档统一，不要为同一控件造多个说法。

### 1.4 `规则/说明` 写法约定
- 全部以动作开头："点击…"、"勾选…"、"选择…"、"输入…"；
- 写清去向与结果："点击后进入对应项目的需提交待办详情页"；
- 有二次确认必须写明："弹出框询问用户是否删除"；
- 有权限约束要带出角色："项目负责人、项目创建人可对项目详情进行编辑"；
- 不写技术实现（接口名、表名、SQL）。

## 六、常用句式库

### 权限
- `菜单权限：<角色>拥有该菜单权限。`
- `菜单权限：登录用户均有首页权限`
- `菜单权限：不涉及` / `功能权限：不涉及`
- `列表数据权限：<角色>可查看<数据范围>`
- `使用人员：<角色名>`
- `维护－包括：新建、下载样本、导入项目、查询、项目详情。`
- `查看－包括：查询、项目详情。`
- `编辑－项目负责人、项目创建人`

### 功能描述
- `数据来源：<来源>` / `数据来源：` + 逐条
- `配置菜单：<一级>－<二级>－<三级>`
- `状态划分：无`
- `操作说明：`
- `界面原型图：`
- `字段逻辑：不涉及` / `字段逻辑：`
- `新增“<筛选项>”筛选项，<哪几个列表>都增加。`

### 对接类（H2 系统对接需求）
- `模块：<模块名>`
- `需求说明：`
- `参考<系统>提供的接口文档，实现<A>向<B>同步<数据>。`
- `客户提供数据中心的连接方式、数据库表及原来的同步视图脚本。`

### 定制需求出处标注
- `定制需求梳理清单原始条目（第 4 部分）`

### 备注/批注
- 用 `annotation text` 样式（styleId 12），例如：`已经报送的就不要再次提醒。`
- 编写说明允许"蓝色斜体字作为注释或举例"。

## 七、写作口径

- 人称：业务视角，主语是"系统"或角色名，不出现"我们/我认为"。
- 时态：陈述现状用"目前…"，写需求用"支持…/可…/需…"。
- 单位：日期用 `YYYY-MM-DD` 或 `xxxx年xx月xx日`，与人名/条目保持一致即可。
- 禁止：写实现方案（表名、接口名、代码类名）、写工作量、写排期——这些属需求变更单/工作量评估表，不在需求规格说明书内。
