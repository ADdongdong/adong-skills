## 二、正文直接格式（★ 光靠样式不够，主文档全靠直接格式控制排版）

主文档正文段落**不使用样式默认值**，而是逐段写死直接格式。要让新写的段落与主文档视觉一致，必须照抄下列参数（实测自 v4.0.5 的 3187 个段落）：

| 元素 | 段落级（pPr） | 字符级（rPr） |
|---|---|---|
| **普通正文段落** | `<w:spacing w:line="360" w:lineRule="auto"/>`（1.5 倍行距） | `<w:rFonts w:ascii="宋体" w:hAnsi="宋体" w:eastAsia="宋体" w:cs="宋体" w:hint="eastAsia"/>` + `<w:sz w:val="24"/>`（12pt） |
| **用户场景正文** | 同上 + `<w:ind w:firstLine="420" w:firstLineChars="0"/>`（首行缩进 2 字符） | 同上 |
| **各级标题** | `<w:spacing w:line="360" w:lineRule="auto"/>` | 仅 `<w:rFonts w:hint="eastAsia"/>`（**不要**覆盖字体字号，交给 heading 样式） |
| **表格单元格** | `<w:spacing w:before="0" w:after="0" w:line="360" w:lineRule="auto"/>` | 同上（宋体 12pt） |

要点：
- 行距最关键。样式默认不是 1.5 倍，**每个段落都要显式写 `line=360`**，否则间距明显偏紧。
- 正文字体要连 `w:ascii` 一起设成宋体；只设 eastAsia 会导致数字/英文落到样式里的 Calibri，肉眼可见不一致。
- 标题不要设 `sz`/`rFonts ascii`，否则会顶掉 heading 样式定义的字号字体层级。
- 缩进只有「用户场景」正文需要（首行 420 twips）；权限说明、功能描述、补充说明的条目**不缩进**（主文档即如此）。
- 脚本里对应 `fmt_para()` / `fmt_run()` 两个 helper，`req()` 已对用户场景自动加缩进。


## 三、标题多级自动编号（关键）

- 所有 `heading 1..6` 共用 `numId=1`（`abstractNumId=30`），层级 `ilvl=0..5`。
- 编号格式（`numFmt=decimal`）：

| ilvl | lvlText | 效果 |
|---|---|---|
| 0 | `%1.` | `1.` |
| 1 | `%1.%2.` | `1.1.` |
| 2 | `%1.%2.%3.` | `1.1.1.` |
| 3 | `%1.%2.%3.%4.` | `1.1.1.1.` |
| 4 | `%1.%2.%3.%4.%5.` | `1.1.1.1.1.` |
| 5 | `%1.%2.%3.%4.%5.%6.` | `1.1.1.1.1.1.` |

**因此**：标题文字里**绝对不要手写"1.1"这类序号**，序号由样式自动生成；插入/删除章节后编号自动重排。若某个标题出现在目录之外（如封面、题注）却被套了 heading 样式，会导致后续编号错位——用 Normal 样式。

## 五、表格版式约定

- 一律使用 `Table Grid`。
- 列宽合计不超过正文区宽度（A4 纵向减去左右页边距，约 15 cm）。
- 建议采用「固定列宽 + 表宽 100%」：`tblW type=pct w=5000`、`tblLayout type=fixed`，并同步写 `tblGrid` 的 `gridCol` 宽度，否则 Word 会按内容重排列宽、导致同一文档内表格宽窄不一。
- 表头行可加浅底纹（`DCE6F1` 一类）便于区分，非强制。
- 长表格允许跨页，不要手动拆表。

## 六、图片与图注

- 截图直接嵌入正文段落，宽度按正文区（约 15 cm）等比缩放。
- 多张图时在每张图上方用 `列出段落1`（styleId 25）写图注，冒号结尾，例如：`查询结果：`、`我的借阅页面：`、`界面原型图：`。
- 截图要求：能看清字段名与按钮文案；涉及数据的截图先脱敏。

## 七、用脚本时的样式取用方式

`scripts/build_req_spec.py` 内部按 **styleId** 取样式（原文档样式名是小写 `heading N`，python-docx 会规范化，按名字取容易踩坑）：

```python
SID = {'Normal': '1', 'h1': '2', 'h2': '3', 'h3': '4', 'h4': '5', 'h5': '6', 'h6': '7'}
```

## 八、常见格式事故

| 现象 | 原因 | 处理 |
|---|---|---|
| 标题序号乱/重复 | 手写了序号，或正文段落被套了 heading 样式 | 删掉手写序号；正文改回 Normal |
| 表格宽窄不一、超出页边距 | 未设固定列宽与 tblGrid | 按第四节设置 |
| 目录不更新 | TOC 域未刷新 | Word/WPS 中全选后 F9 |
| 字体被替换 | 用了新样式或直接设 run 字体 | 只继承模板样式，不覆盖字体 |
